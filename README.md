# 孕前BMI与子代摄食相关研究

## 项目背景
本项目旨在探讨孕前母亲BMI对子代食物摄入行为的影响。科学假设：孕前较高BMI可能通过宫内环境、表观遗传或母婴喂养行为等途径，影响子代对高热量/高糖食物的偏好及摄入量。

## 文件夹用途说明
- **analysis/**：存放所有分析脚本（01-04编号脚本）
- **data-raw/**：原始数据（Excel等，不要上传隐私数据）
- **data/**：清洗后的干净数据
- **manuscript/**：论文草稿、报告、表格
- **R/**：可重复使用的自定义函数（可选）

## 如何运行
1. 点击页面右上角绿色 **Code** 按钮 → **Download ZIP** 下载整个项目
2. 解压后，用 **RStudio** 打开 `.Rproj` 文件
3. 依次运行 analysis/ 下的 01 → 02 → 03 → 04 脚本
